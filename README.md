# 🚗 Audi RS7

Uma página web desenvolvida para apresentar o **Audi RS7**, destacando seu desempenho, design e principais especificações.

## 📖 Sobre o projeto

O projeto consiste em uma landing page inspirada no Audi RS7, com uma interface moderna e esportiva.

A página apresenta informações sobre o veículo, incluindo:

- ⚡ Desempenho
- 🏎️ Potência
- 🚀 Velocidade máxima
- 🔧 Motor
- 🎨 Design
- 📱 Layout responsivo

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 📋 Informações apresentadas

O site apresenta algumas das principais características do Audi RS7:

| Característica | Informação |
|---|---|
| 0–100 km/h | 3,6 segundos |
| Potência | 600 cv |
| Velocidade máxima | 305 km/h |
| Motor | 4.0 V8 TFSI Biturbo |

## 🎨 Design

A interface utiliza uma estética inspirada no universo **Audi Sport**, com:

- Fundo escuro;
- Detalhes em vermelho;
- Tipografia moderna;
- Cards de especificações;
- Efeitos de transição;
- Animações;
- Layout responsivo para dispositivos móveis.
